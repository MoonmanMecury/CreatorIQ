## 2025-05-14 - Parallelizing Independent I/O Tasks in C#
**Learning:** In the `TrendService` and `YouTubeService`, multiple independent I/O operations (calling a Python script and fetching YouTube metrics/statistics) were being executed sequentially. Parallelizing these using `Task.WhenAll` significantly reduces total response time, as the latency becomes determined by the longest-running task rather than the sum of all tasks. Additionally, extracting `channelId` from initial search results allows channel statistics fetching to overlap with video statistics fetching, saving a sequential network hop.
**Action:** Always check if subsequent async calls depend on the result of the previous one. If not, initiate them concurrently and await them together using `Task.WhenAll`.
